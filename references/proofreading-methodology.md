# 校对方法论

提炼自出版行业校对实践，作为 `editor` Skill 的底层知识参考。

## 四大错误分类

### 1. 机械性差错（最低级，最易犯）

**字词错误：**
- 拼音输入法同音字：必须/必需、交代/交待、权利/权力、启事/启示、不堪/不刊
- 五笔/笔画形近字：己/已/巳、大/太/犬、未/末、人/入、干/千/于
- 常见错别字：再接再厉（励）、川流不息（穿）、一筹莫展（愁）、一鼓作气（股）

**助词误用（的地得）：**
- 的 + 名词：美丽的花、他写的文章
- 地 + 动词：慢慢地走、仔细地看
- 得 + 补语：跑得快、写得好、高兴得跳起来
- 口诀：名前白勺`的`、动前土也`地`、动后形前双人`得`

**标点符号（中文全角为准）：**
- 逗号 `，` 不要用 `,`
- 句号 `。` 不要用 `.`
- 分号 `；` 不要用 `;`
- 冒号 `：` 不要用 `:`
- 引号 `""` 不要用 `""`
- 破折号 `——`（两个 em-dash 或一个二字线）
- 省略号 `……`（两个字符，六点）
- 书名号 `《》`，嵌套时外层双书名号内层单书名号 `< >`
- 引文末尾标点：完整引述句号在引号内，部分引用或嵌入句中时在引号外

### 2. 语法与逻辑性差错（最影响阅读体验）

**成分残缺或赘余：**
- 缺主语："通过这次调查，让我认识到问题" → 删"通过"或"让"
- 缺宾语："他获得了大家一致" → 补"好评"
- 赘余："反复多次""凯旋归来""目前的现状"

**语序颠倒：**
- 修饰语错位："把问题解决" vs "解决问题"（补语位置）
- 多层定语顺序混乱

**关联词错配：**
- 虽然……但是（不是"虽然……而且"）
- 因为……所以（不是"因为……因此"）
- 不但……而且（不是"不但……却"）

**逻辑断层或矛盾：**
- 前文说 A，后文结论跳到 B，中间缺推理
- 数量/时间前后矛盾

### 3. 事实与知识性差错（最致命的硬伤）

- 历史年代错误："唐朝人吃番茄炒蛋"（番茄明朝才传入中国）
- 人名写错、张冠李戴名言归属
- 数据前后矛盾：前文"历时 3 个月"，后文"这半年"
- 书名/作品名写错
- 专业术语写错
- 公司名/品牌名拼写错误
- 违反物理/地理/生活常识

### 4. 格式与体例差错（最影响专业度）

- 标题层级混乱（一、→ 1. → (1) 不统一）
- 字体字号不一致
- 段首缩进不统一
- 空行/分段不一致

## 对抗"自我校对盲区"的技巧

人类大脑自带自动纠错功能（认知心理学中称为"字形错觉"），对自己刚写的内容尤其容易脑补。以下技巧用于对抗这种惯性：

1. **冷处理：** 写完至少放几小时再看，打破创作亢奋状态
2. **朗读法：** 出声读或 TTS 机器读，听觉是对抗视觉脑补的最强武器
3. **逆读法（倒读）：** 从段落最后一个字往前读，破坏语境，错别字无所遁形
4. **拆读法（洋葱法）：** 第一遍只看文字，第二遍专盯标题，第三遍专盯数据
5. **换视觉环境：** 换字体、换字号、换背景色、打印出来看

## 常见雷区速查

| 类型 | 示例 | 说明 |
|---|---|---|
| 叠字遗漏 | "政治停摆停摆" → 重复叠字 | 打字手滑 |
| 同音错字 | "不可理喻 → 不可鲤鱼" | 拼音输入法 |
| 形近错字 | "己/已/巳""侯/候" | 五笔或笔画 |
| 标点混用 | 中文里出现 `,` `.` `;` `:` | 中英切换 |
| 的地得 | "做的很好 → 做得很好" | 高频错误 |
| 数字矛盾 | "历时3个月…这半年…" | 时间线不一 |
| 书名错误 | 书名号内书名写错或出版社搞混 | 事实硬伤 |
| 网络用语 | "PUA""CPU""KTV" 等误用 | 语义漂移 |
